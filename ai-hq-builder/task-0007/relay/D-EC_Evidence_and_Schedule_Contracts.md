# D-EC — Evidence-Purpose and Schedule-Transaction Contracts (P2Y design portions, ratified)

**Provenance:** the four behavioral/authority contracts specified by the verifier in `46_` §3, adopted verbatim as design rulings by owner-arbitrated decision (trail entries 110–111), encoded and behaviorally demonstrated in the TASK-0005 R4 return. This artifact anchors them in the design corpus; the build gate implements them with real cryptography, persistence, and clocks per `13B_`.

1. **Evidence-purpose governance (P2Y-01):** which evidence purposes are valid for an action is determined by an independently governed mapping — `ActionEvidenceContract` rows keyed by (action class, scope, policy version, risk/data class), held in a bound policy-plane artifact authored by an authority distinct from both the evidence source and the receipt authority. A consuming action can never self-declare the purpose that authorizes it; a declared contract id is checked against the lookup, never trusted.
2. **Schedule-transaction invariants (P2Y-02):** the eight logical invariants of `46_` §3, schedule-scoped — in-force predecessor required; one transaction = one schedule = one adoption; complete retirement set; retirement references a defined version of the same schedule; transaction identity cannot bridge schedules; no version both active and retired; missing/duplicated/asymmetric/cross-schedule transactions refuse replay before state exists.
3. **Legal recurrence admission (P2Y-03):** one normative recurrence schema validated identically at every entry point (registration, change, journal replay) — a journal cannot represent a state the governed API itself would refuse; typed fields, positive periods, per-kind required and prohibited fields.
4. **Receipt-occurrence temporal validity (P2Y-04):** a run receipt satisfies only an occurrence its recurrence actually produces, within that occurrence's admissible window; early-execution allowance is an explicit schedule policy (`max_early_ticks`, default 0), never the accidental result of accepting any (version, occurrence) pair.
